## Overview

Fortnite Tracker provides detailed statistics for Fortnite players — K/D ratio, win rate, placement distributions, input method breakdowns, seasonal progression, and leaderboard rankings. It reads public Epic Games API data and presents it in an easy-to-read dashboard accessible from any browser.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Fortnite Tracker** delivers the features you need in a clean, intuitive package.

> Official website: [fortnitetracker.com](https://fortnitetracker.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Match Statistics** | Comprehensive K/D, win rate, and placement stats per season |
| **Input Breakdown** | Stats separated by input method — keyboard, controller, touch |
| **Seasonal Data** | Historical stat tracking across every Fortnite season and chapter |
| **Leaderboards** | Global and regional leaderboard rankings by score, wins, and kills |
